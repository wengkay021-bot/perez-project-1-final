# Perez Project 1 — Lewelyn E. Perez

A responsive personal portfolio made with HTML and CSS.

## Project structure

```text
perez-project-1/
├── index.html
├── README.md
├── styles/
│   └── style.css
└── assets/
    └── profile.jpg
```

## Before publishing
1. Replace the placeholder education details with your real school, course, and year level.
2. Edit the About Me, skills, and project descriptions so they are accurate.
3. Add your email and GitHub profile link.
4. Replace `assets/profile-placeholder.svg` with your own image. Keep the filename `profile.jpg` if you also update the image path in `index.html`, or keep the current SVG placeholder.
5. Open `index.html` in a browser to preview the website.

## Run locally
Double-click `index.html`, or open it in a browser.

## GitHub Pages
Upload the contents of this project folder to a GitHub repository named `perez-project-1`. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the public website URL.

## Suggested 10-commit development history
Make these commits as you complete each stage (do not create fake commits all at once):

1. `Create project folder and initial files`
2. `Add basic HTML document structure`
3. `Add portfolio navigation and hero section`
4. `Add about me section`
5. `Add educational background section`
6. `Add skills section`
7. `Add projects and contact sections`
8. `Create CSS stylesheet and color theme`
9. `Make portfolio responsive for mobile devices`
10. `Finalize content and prepare GitHub Pages deployment`
